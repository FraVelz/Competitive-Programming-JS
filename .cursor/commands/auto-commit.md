# Autocommit — programing-competitive (OmegaUp / LeetCode)

Usar cuando el usuario pida **hacer commit**. Mensajes **Conventional Commits** en inglés. **No** push salvo petición explícita.

## Cuándo ejecutar

- **`/auto-commit`** o petición explícita de commit.

## Antes de commitear

1. `git status` / `git diff` / `git log -15 --oneline`
2. **Respetar borrados** y renombres de archivos de ejercicios.

## Scopes habituales

`omegaup`, `leetcode`, `notes`, `cursor`, `feat`, `chore`.

Rutas: `omegaup/`, `leetcode/`, `notes/`, `.cursor/`.

## Reglas

- Cumplir `.cursor/rules/git-commits.mdc`.
